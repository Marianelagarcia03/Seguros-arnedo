Generar las claves del panel

Todo se calcula en este navegador: la contraseña no se envía a ningún lado. Después copiá cada valor en Netlify → Site configuration → Environment variables, marcalos como secretos y volvé a publicar el sitio.

Variables para Netlify

Guardá una copia de DATA_KEY en un lugar seguro (por ejemplo, un gestor de contraseñas). Con ella se cifran los CBU y las tarjetas: si se pierde o se cambia, no se pueden volver a leer los que ya se guardaron. Para cambiar solo la contraseña más adelante, generá de nuevo y actualizá únicamente ADMIN_PASS_HASH.
