# Logo SegurosArnedo.com

| Archivo | Para qué sirve |
|---|---|
| `logo-segurosarnedo-editable.svg` | Versión editable: el nombre y el lema son texto. Se abre con Inkscape, Illustrator, Figma o Canva (importar SVG). Usa la fuente **Montserrat** (gratuita, Google Fonts): instalala para verla igual. |
| `logo-segurosarnedo.svg` | Versión final con el texto convertido en curvas: se ve igual en cualquier computadora. Usala para imprimir o enviar a terceros. |
| `logo-segurosarnedo-1200.png` | Imagen de alta resolución (1200 × 1200), por ejemplo para el perfil de Google o redes. |
| `logo-jma-seguros-anterior.png` | El logo anterior, como referencia. |

Colores: fondo azul marino `#0F1D37`, ícono `#E6E6E4`, texto dorado `#B09A3E`.

Las versiones que usa el sitio están en `img/logo.png`, `img/web/logo-160.*`, `img/web/icon-192.png`, `img/web/apple-touch-icon.png` y `img/web/favicon-32.png`. Si cambiás el logo, regenerá esas imágenes a partir del SVG.
